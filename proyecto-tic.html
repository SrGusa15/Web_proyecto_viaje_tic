PROYECTO ESCOLAR

Criterios y competencias TIC

Sostenibilidad

El proyecto contempla el uso de transporte ferroviario para los desplazamientos internos cuando la planificación final lo permita.

Accesibilidad

La información se organiza en páginas y bloques claros, con diseño adaptable a pantallas grandes, tabletas y móviles.

Gestión del proyecto

La planificación del itinerario, las tareas y el control de costes forman parte del trabajo interdisciplinar.

ARQUITECTURA

Tecnologías utilizadas

HTML5 y CSS3

Estructura semántica, estilos compartidos, variables de diseño, distribución en rejillas y adaptación responsive.

JavaScript

Cuenta atrás, menú móvil, preferencia de tema, cálculo de la tienda, mapa y comunicación con el diario.

Flask y SQLite

API del diario alojada en un equipo propio y persistencia de entradas en una base de datos ligera.

Leaflet y CARTO

Mapa interactivo con marcadores geográficos para las principales paradas del recorrido.

GitHub Pages

Versionado del código y publicación estática del frontend desde el repositorio.

Cloudflare Tunnel

Acceso HTTPS al backend local sin publicar directamente un puerto del router. El túnel debe permanecer activo.

DEL NAVEGADOR A LA BASE DE DATOS

Cómo se conectan las piezas

01 · Frontend

GitHub Pages entrega HTML, CSS y JavaScript al navegador del visitante.

02 · API

El script del diario solicita datos por HTTPS a través del túnel de Cloudflare.

03 · Persistencia

Flask procesa las peticiones y almacena las entradas en SQLite en la tablet HP ElitePad.
