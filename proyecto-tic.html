Documentación del despliegue en servidor propio y pasarela de formularios.

Arquitectura del Proyecto

Frontend Estático

Sitio web programado en HTML5, CSS3 y JavaScript vanilla en Neovim. Alojado y desplegado con integración continua en GitHub Pages.

Servidor On-Premise

Infraestructura física local alojada en una tablet servidor HP EliteBook ejecutando el entorno XAMPP (Apache + MySQL + PHP).

Cloudflare Zero Trust

Exposición del servidor local a Internet mediante túnel inverso cifrado cloudflared, superando restricciones de CGNAT y cortafuegos de red escolar.

Cartografía Esri Dark

Motor de mapas interactivo con Leaflet.js consumiendo teselas oscuras de ArcGIS (World Dark Gray Base) sin dependencia de API keys restrictivas.
