Panel Técnico y Documentación TIC

Arquitectura de sistemas, infraestructura de red e integración de formularios.

Arquitectura del Sistema

1. Frontend Estático (GitHub Pages)

Desplegado sobre la red CDN de GitHub Pages. Implementa HTML5, CSS3 con variables dinámicas para modo oscuro y JavaScript vanilla sin librerías pesadas para garantizar la máxima velocidad de carga.

2. Cartografía Interactiva (Esri Dark API)

Integración del motor de mapas Leaflet.js alimentado por los servidores geográficos de Esri ArcGIS (World Dark Gray Base). Proporciona una interfaz estética en modo noche sin dependencia de APIs comerciales ni limitaciones de peticiones.

3. Servidor Local On-Premise y Blog Colaborativo

Infraestructura física montada sobre una tablet servidor HP EliteBook ejecutando el stack XAMPP (Apache + MySQL + PHP) con un CMS WordPress configurado multi-usuario.

4. Enrutamiento y Seguridad (Cloudflare Tunnels)

Para exponer el servidor local a Internet sin abrir puertos en el router ni sufrir bloqueos por CGNAT o proxies escolares, se utiliza la herramienta daemon cloudflared. Establece un túnel inverso cifrado SSL (HTTPS) directo entre el equipo y la red global de Cloudflare.
